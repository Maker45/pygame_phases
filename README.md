# pygame_phases

Pygame lessons organized in five phases.

📊 **Slides:** [File Management: Pygame Phases](https://docs.google.com/presentation/d/1NWoVOSkbLrdqzcc2O6VAjUIfl8c8bPD4AcnOjmQHHx4/view)

**Students:** see [STUDENTS.md](STUDENTS.md) for how to download the files and get updates.

```
pygame_phases/
  phase1_basics/       01_moving_square.py, 02_dvd_screensaver.py
  phase2_physics/      01_keyboard_dodger.py, 02_survival_mode.py
  phase3_lists/        01_50_stars.py, 02_galaxy_grazer.py, 03_hungry_block.py, 04_stat_tracker.py
  phase4_functions/    01_function_refactor.py, 02_asset_manager.py, images/
  phase5_gotcha_labs/  01_bitwise_gotchas.py, 02_slicing_gotchas.py, 03_casting_gotchas.py, 04_terminal_mini_test.py
```

Each phase folder has a `README.md` with the assignment directions.

Requires Python 3 and `pip install pygame`.
